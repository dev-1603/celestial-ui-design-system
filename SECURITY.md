# Security Policy

## Supported Versions

The following table lists the versions of the project that are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

_(Note: The project is currently in pre-release. Version 1.0 will be supported once released)._

## Reporting a Vulnerability

Please do not report security vulnerabilities on the public GitHub issue tracker.

Since this repository is currently in its initial phase without a designated security email, please privately disclose vulnerabilities by reaching out to the repository maintainers through appropriate private channels (e.g., direct email to a maintainer).

We take security seriously and will evaluate all reports promptly.
