# Packages

Published foundation packages for the Celestial UI design system.

| Package                            | Description                                                               |
| ---------------------------------- | ------------------------------------------------------------------------- |
| [`@celestial-ui/tokens`](./tokens) | Canonical design tokens, resolver, validation, and generators             |
| [`@celestial-ui/theme`](./theme)   | Theme identity, modes, inheritance, tenant profiles, and resolution       |
| [`@celestial-ui/styles`](./styles) | CSS compiler, runtime, SSR, and optional Tailwind/shadcn bridges          |
| [`@celestial-ui/icons`](./icons)   | Provider-neutral icon catalogues, resolution, fallback, and adapters      |
| [`@celestial-ui/core`](./core)     | Framework-agnostic component contracts, behavior controllers, and runtime |

See [../docs/package-usage.md](../docs/package-usage.md) for the full ecosystem guide.
